# Практическое задание

## Первый веб-проект на HTML, CSS и JavaScript

### Цель

В этом задании вам нужно самостоятельно создать небольшой одностраничный сайт, используя три основные технологии frontend-разработки:

- HTML — для структуры страницы;
- CSS — для оформления;
- JavaScript — для интерактивности.

Главная цель задания — не просто получить красивую страницу, а показать, что вы понимаете базовую структуру веб-проекта и умеете правильно связывать между собой HTML-, CSS- и JavaScript-файлы.

После выполнения задания у вас должен получиться полностью запускающийся локальный веб-проект, который открывается в браузере и корректно работает без дополнительных библиотек и фреймворков.

В рамках задания вам нужно продемонстрировать понимание следующих тем:

- структура HTML-документа;
- подключение CSS;
- подключение JavaScript;
- работа с HTML-тегами;
- использование классов и `id`;
- создание папок проекта;
- работа с относительными путями;
- изменение внешнего вида страницы через CSS;
- обработка нажатия на кнопку через JavaScript;
- использование DevTools для проверки работы проекта.

# Задание

Создайте персональную страницу начинающего frontend-разработчика.

Страница должна содержать информацию о вас как о студенте, который только начинает изучать веб-разработку.

Пример содержания:

```text
Frontend Student

Иван Петров

Я начинаю изучать веб-разработку
и хочу научиться создавать
современные сайты.

Что я изучаю:

HTML
CSS
JavaScript
Tailwind CSS

[ Показать сообщение ]
```

При этом не нужно полностью повторять пример. Вы можете использовать своё имя, описание, название направления и собственные формулировки.

# Шаг 1. Создайте папку проекта

Создайте отдельную папку.

Например:

```text
frontend-first-project
```

Внутри проекта создайте следующую структуру:

```text
frontend-first-project/
│
├── index.html
├── style.css
└── script.js
```

Обратите внимание на названия файлов.

Они должны называться именно:

```text
index.html
style.css
script.js
```

Не допускайте вариантов:

```text
index.html.txt
style.css.txt
script.js.txt
```

# Шаг 2. Создайте базовый HTML-документ

В файле `index.html` создайте полноценную структуру HTML-документа.

На странице обязательно должны присутствовать:

```html
<!DOCTYPE html>
```

корневой элемент:

```html
<html></html>
```

раздел:

```html
<head></head>
```

и:

```html
<body></body>
```

Также добавьте:

```html
<meta charset="UTF-8" />
```

и настройку viewport:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Добавьте название вкладки браузера через:

```html
<title>
```

Например:

```html
<title>Моё первое портфолио</title>
```

# Шаг 3. Подключите CSS

Подключите файл:

```text
style.css
```

к HTML.

Для этого внутри `head` используйте:

```html
<link rel="stylesheet" href="style.css" />
```

После подключения обязательно проверьте, что CSS действительно работает.

Например, временно установите для страницы другой фон.

Если фон изменился, значит файл подключён правильно.

# Шаг 4. Создайте основной контейнер страницы

Внутри `body` создайте основной блок страницы.

Например:

```html

```

Внутри него разместите карточку профиля.

Например:

```html

```

Таким образом, структура должна начинать выглядеть примерно так:

```html
<body>
  <main class="page">
    <section class="profile"></section>
  </main>
</body>
```

# Шаг 12. Добавьте обработчик кнопки

Теперь сделайте так, чтобы при нажатии на кнопку JavaScript показывал сообщение.

В файле `script.js` найдите кнопку:

```javascript
const button = document.querySelector("#messageButton");
```

После этого добавьте обработчик события:

```javascript
button.addEventListener("click", function () {
  alert("Мой первый JavaScript работает!");
});
```

После обновления страницы нажмите на кнопку.

Должно появиться всплывающее сообщение.

# Шаг 13. Добавьте изменение текста через JavaScript

Усложним интерактивность.

Получите главный заголовок:

```javascript
const studentName = document.querySelector("#studentName");
```

Теперь при нажатии на кнопку измените его содержимое.

Например:

```javascript
studentName.textContent = "Будущий frontend-разработчик";
```

Итоговая логика может выглядеть так:

```javascript
const button = document.querySelector("#messageButton");

const studentName = document.querySelector("#studentName");

button.addEventListener("click", function () {
  studentName.textContent = "Будущий frontend-разработчик";

  alert("JavaScript успешно изменил страницу!");
});
```

Теперь одно нажатие выполняет сразу два действия:

```text
изменяет HTML-текст
+
показывает сообщение
```

# Шаг 14. Оформите страницу через CSS

Перейдите в:


```html
  <body>
```

Если `style.css` находится рядом с `index.html`:



Если `script.js` находится рядом с `index.html`:

```html
<script src="script.js"></script>
```

Лучше разместить эту строку непосредственно перед:

```html
</body>
```

## Подсказка 4. Как найти элемент по id

HTML:

```html
<button id="messageButton">Нажать</button>
```

JavaScript:

```javascript
const button = document.querySelector("#messageButton");
```

Обратите внимание на:

```javascript
#
```

Он используется перед именем `id`.

## Подсказка 5. Как обработать нажатие

```javascript
button.addEventListener("click", function () {
  alert("Кнопка работает");
});
```

`click` означает событие нажатия на элемент.

## Подсказка 6. Как изменить текст

HTML:

```html
<h1 id="title">Старый текст</h1>
```

JavaScript:

```javascript
const title = document.querySelector("#title");

title.textContent = "Новый текст";
```

Лучше:


Следите за отступами в HTML.

Хорошая структура:

```html
<section>
  <h1>Заголовок</h1>

  <p>Описание</p>
</section>
```

читается значительно легче, чем весь код, записанный одной строкой.

Не добавляйте десятки случайных CSS-свойств только ради оформления. Каждое изменение должно иметь понятную цель.

Например:

```css
background-color
```

отвечает за фон.

```css
color
```

— за цвет текста.

```css
font-size
```

— за размер текста.

```css
padding
```

— за внутренние отступы.

```css
border-radius
```

— за скругление углов.

Если что-то перестало работать, не удаляйте сразу весь код. Проверяйте проблему по частям.

Если исчезло оформление — проверяйте CSS.

Если не работает кнопка — проверяйте JavaScript и Console.

Если не отображается картинка — проверяйте путь к изображению.

Если страница вообще выглядит странно — проверяйте структуру HTML.

Обязательно используйте DevTools. Даже на первом занятии это должен становиться привычным инструментом, а не чем-то, что используется только преподавателем.

Перед отправкой проекта закройте браузер, снова откройте `index.html` и проверьте проект как будто вы видите его впервые. Это помогает обнаружить ошибки, которые могли остаться незаметными во время разработки.

Главный результат задания — вы должны уметь объяснить каждую из трёх частей проекта:

```text
index.html
```

создаёт структуру страницы.

```text
style.css
```

отвечает за её оформление.

```text
script.js
```

добавляет интерактивное поведение.

Если вы можете самостоятельно создать эти файлы, правильно их подключить, запустить проект, найти элемент страницы через JavaScript и обработать нажатие на кнопку, значит основная цель первого практического задания достигнута.
