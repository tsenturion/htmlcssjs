# Практическое задание

# Создание первого интерфейса на Tailwind CSS

## Цель

Научиться использовать базовые utility-классы Tailwind CSS для создания простого современного интерфейса.

В ходе выполнения задания необходимо закрепить понимание связи между обычным CSS и Tailwind CSS. Студент должен научиться создавать HTML-разметку и оформлять её только через классы Tailwind, используя цвета, размеры, отступы, типографику, границы и базовое расположение элементов.

После выполнения задания вы будете уметь создавать простой компонент интерфейса без написания отдельного CSS-файла.

# Задание

Необходимо разработать страницу карточки образовательного курса на Tailwind CSS.

Итоговый результат должен представлять собой современную карточку курса, которую можно использовать на сайте образовательной платформы.

Карточка должна содержать:

название курса;

описание курса;

изображение;

информацию о длительности обучения;

кнопку действия;

визуальное оформление через Tailwind CSS.

Все стили должны быть выполнены только через классы Tailwind.

Использование отдельного файла CSS запрещено.

# Шаг 1. Создать структуру проекта

Создать папку проекта:

```
tailwind-course-card
```

Внутри создать файл:

```
index.html
```

Подключить Tailwind CSS.

Пример структуры:

```
tailwind-course-card

│
├── index.html
│
└── images
    └── course.jpg
```

# Шаг 2. Создать HTML-структуру карточки

Создать основной контейнер карточки.

Пример структуры:

```html
<div>
  <img />

  <h2></h2>

  <p></p>

  <div>Длительность курса</div>

  <button></button>
</div>
```

Необходимо использовать семантические HTML-теги:

```
section
article
img
h2
p
button
```

# Шаг 3. Добавить изображение курса

Добавить изображение в верхнюю часть карточки.

Требования:

изображение должно занимать всю ширину карточки;

изображение должно иметь фиксированную высоту;

изображение не должно искажаться;

углы изображения должны быть закруглены.

Использовать Tailwind-классы:

```
w-full
h-*
object-cover
rounded-*
```

# Шаг 4. Создать внешний вид карточки

Основной блок карточки должен иметь:

белый фон;

закругленные углы;

тень;

внутренние отступы;

ограниченную ширину.

Использовать классы:

```
bg-white
rounded-xl
shadow-lg
p-*
max-w-*
```

Пример результата:

```html
<article
  class="
bg-white
p-6
rounded-xl
shadow-lg
max-w-sm
"
></article>
```

# Шаг 5. Оформить заголовок курса

Создать название курса.

Например:

```
Frontend-разработка
```

Настроить:

размер текста;

жирность;

цвет;

отступы.

Использовать:

```
text-*
font-*
text-gray-*
mt-*
mb-*
```

Пример:

```html
<h2
  class="
text-2xl
font-bold
text-gray-900
"
>
  Frontend-разработка
</h2>
```

# Шаг 6. Оформить описание курса

Добавить короткое описание.

Например:

```
Изучение HTML, CSS, JavaScript и создание современных веб-интерфейсов.
```

Настроить:

размер текста;

цвет;

межстрочный интервал.

Использовать:

```
text-base
text-gray-600
leading-*
```

# Шаг 7. Создать информационный блок

Добавить дополнительный блок:

```
Длительность:
6 месяцев
```

или:

```
Уровень:
Начинающий
```

Оформить его как отдельный элемент интерфейса.

Использовать:

```
bg-gray-100
rounded-lg
px-*
py-*
text-sm
```

Пример:

```html
<div
  class="
bg-gray-100
rounded-lg
px-4
py-2
text-sm
"
>
  6 месяцев обучения
</div>
```

# Шаг 8. Создать кнопку

Добавить кнопку:

```
Записаться на курс
```

Кнопка должна иметь:

цвет фона;

белый текст;

внутренние отступы;

закругление;

эффект при наведении.

Использовать:

```
bg-purple-600
text-white
px-*
py-*
rounded-lg
hover:bg-*
```

Пример:

```html
<button
  class="
bg-purple-600
text-white
px-6
py-3
rounded-lg
hover:bg-purple-700
"
>
  Записаться
</button>
```

# Шаг 9. Добавить расположение элементов

Настроить расстояния между блоками.

Карточка должна выглядеть аккуратно:

изображение не должно прилипать к тексту;

заголовок должен иметь расстояние от изображения;

кнопка должна находиться ниже описания.

Использовать:

```
space-y-*
mt-*
mb-*
gap-*
```

Например:

```html
<div class="space-y-4"></div>
```

# Шаг 10. Добавить адаптивность

Карточка должна корректно отображаться на разных экранах.

Добавить:

на мобильном устройстве карточка занимает всю доступную ширину;

на большом экране карточка имеет ограниченную ширину.

Использовать:

```
w-full
sm:w-*
md:w-*
lg:w-*
```

Пример:

```html
<article
  class="
w-full
md:max-w-md
"
></article>
```


# Подсказки по ключевым частям

## 1. Размеры элементов

В Tailwind размеры задаются через сокращённые классы.

CSS:

```css
width: 100%;
```

Tailwind:

```html
w-full
```

CSS:

```css
max-width: 400px;
```

Tailwind:

```html
max-w-sm
```

## 2. Отступы

В Tailwind:

```
p
```

означает padding.

```
m
```

означает margin.

Дополнительные направления:

```
t
```

верх;

```
b
```

низ;

```
x
```

горизонтальное направление;

```
y
```

вертикальное направление.

Примеры:

```html
p-6
```

внутренний отступ со всех сторон.

```html
px-4
```

отступ слева и справа.

```html
mt-5
```

внешний отступ сверху.

## 3. Цвета

Пример системы цветов:

```html
bg-blue-500
```

Разбирается как:

```
bg
```

фон.

```
blue
```

цвет.

```
500
```

оттенок.

Примеры:

Фон:

```
bg-gray-100
bg-purple-600
```

Текст:

```
text-gray-700
text-white
```

## 4. Закругления

CSS:

```css
border-radius: 16px;
```

Tailwind:

```
rounded-xl
```

Частые варианты:

```
rounded
rounded-md
rounded-lg
rounded-xl
rounded-full
```

## 5. Тень

CSS:

```css
box-shadow
```

Tailwind:

```
shadow
shadow-md
shadow-lg
shadow-xl
```

Для карточек чаще всего используется:

```
shadow-lg
```

## 6. Эффект наведения

CSS:

```css
button:hover {
}
```

Tailwind:

```
hover:
```

Пример:

```html
hover:bg-purple-700
```

означает:

при наведении изменить цвет фона.

# Советы по улучшению работы

После создания первой версии необходимо улучшить визуальное качество карточки.

Можно добавить:

градиентный фон;

иконку рядом с длительностью курса;

дополнительный бейдж:

```
Популярный курс
```

анимацию кнопки;

эффект увеличения карточки при наведении:

```
hover:scale-105
```

плавность:

```
transition
duration-300
```

например:

```html
<article
  class="
transition
duration-300
hover:scale-105
"
></article>
```

Также рекомендуется попробовать создать несколько вариантов одной карточки:

карточка курса программирования;

карточка дизайна;

карточка языкового курса.

Главная задача — научиться менять внешний вид интерфейса только изменением Tailwind-классов, понимая, какое CSS-свойство стоит за каждой командой.
