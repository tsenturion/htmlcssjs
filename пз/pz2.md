# Практическое задание

## HTML + CSS: создаём страницу учебного курса

### Контекст задания

Представьте, что вы работаете начинающим frontend-разработчиком. Вам передали задачу сверстать простую страницу образовательного курса.

HTML вы уже знаете, поэтому в этой работе нужно показать, что вы умеете не только создавать структуру страницы, но и оформлять её с помощью CSS.

В этом задании пока **не используем Flexbox, Grid, Tailwind CSS и JavaScript**. Наша задача — закрепить базовый CSS:

- подключение таблицы стилей;
- CSS-селекторы;
- классы;
- цвета;
- типографику;
- размеры;
- `margin`;
- `padding`;
- `border`;
- `border-radius`;
- `background`;
- работу с изображениями;
- Box Model;
- `box-sizing`;
- наследование;
- базовую работу с DevTools.

# Цель практического задания

Создать законченную HTML-страницу учебного курса и оформить её с помощью отдельного CSS-файла.

После выполнения задания вы будете уметь:

- правильно связывать HTML и CSS;
- создавать классы и обращаться к ним в CSS;
- оформлять текст;
- задавать цвета и фон;
- управлять шириной элементов;
- использовать внешние и внутренние отступы;
- понимать разницу между `margin` и `padding`;
- создавать рамки и скругления;
- оформлять изображения;
- применять `box-sizing: border-box`;
- находить ошибки CSS через DevTools;
- организовывать HTML и CSS так, чтобы код оставался читаемым.

# Задание

Создайте одностраничный сайт для вымышленного курса:

**«Основы веб-разработки»**

Страница должна содержать несколько смысловых блоков.

Пример структуры:

```text

Заголовок сайта

Краткое описание

Карточка курса

Что вы изучите

Информация о преподавателе

Стоимость

Кнопка записи

Подвал
```

Дизайн вы создаёте самостоятельно.

Главное — выполнить технические требования.

# Шаг 1. Создайте структуру проекта

Создайте отдельную папку:

```text
web-course
```

Внутри неё создайте:

```text
web-course
│
├── index.html
├── style.css
│
└── images
```



# Шаг 2. Создайте базовый HTML-документ

В файле:

```text
index.html
```

создайте полноценную структуру HTML5.

На странице обязательно должны быть:

```html
<!DOCTYPE html>
<html>
  <head>
    <body></body>
  </head>
</html>
```

Добавьте:

```html
<meta charset="UTF-8" />
```

и:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Создайте название страницы:

```html
<title>Основы веб-разработки</title>
```

# Шаг 3. Подключите CSS

Создайте файл:

```text
style.css
```

Подключите его внутри `<head>`.

Используйте:

```html
<link rel="stylesheet" href="style.css" />
```

После подключения временно добавьте в CSS:

```css
body {
  background-color: lightgray;
}
```

Откройте страницу в браузере.

Если фон изменился, CSS подключён правильно.

После проверки цвет можно заменить.

# Шаг 4. Создайте основной контейнер страницы

Внутри `<body>` создайте:

```html
<main class="page"></main>
```

В него будет помещено основное содержимое.

Пример:

```html
<main class="page"></main>
```

Для класса `.page` задайте:

- максимальную ширину;
- внутренние отступы;
- фон;
- внешние отступы.

Например, подумайте, какие свойства можно использовать:

```css
max-width:
margin:
padding:
background-color:
```

Страница не должна растягиваться бесконечно на широком мониторе.

# Шаг 5. Создайте главный заголовок


# Подсказки по ключевым частям

## 1. Если CSS вообще не применяется

Проверьте:

```html
<link rel="stylesheet" href="style.css" />
```

Убедитесь, что файл действительно называется:

```text
style.css
```

Если CSS находится в другой папке, путь должен соответствовать реальной структуре проекта.

## 2. Если класс не работает

HTML:

```html
<div class="course-card"></div>
```

CSS:

```css
.course-card {
}
```

Обратите внимание:

в HTML точка перед названием класса не пишется.

Правильно:

```html
class="course-card"
```

Неправильно:

```html
class=".course-card"
```

## 3. Если нужно сделать отступ внутри карточки

Используйте:

```css
padding
```

Например:

```css
.course-card {
  padding: 24px;
}
```

## 4. Если нужно увеличить расстояние между карточкой и другими элементами

Используйте:

```css
margin
```

Например:

```css
.course-card {
  margin-top: 30px;
}
```

## 5. Если блок слишком широкий

Используйте:

```css
max-width
```

Например:

```css
.page {
  max-width: 900px;
}
```

## 6. Если нужно расположить основной блок по центру

Можно использовать:

```css
margin-left: auto;
margin-right: auto;
```

или сокращённо:

```css
margin: 0 auto;
```

## 7. Если изображение выходит за границы блока

Попробуйте:

```css
.course-image {
  max-width: 100%;
}
```

или:

```css
.course-image {
  width: 100%;
}
```

## 8. Если изображение выглядит растянутым

Если одновременно заданы ширина и высота:

```css
.course-image {
  width: 100%;
  height: 300px;
}
```

добавьте:

```css
object-fit: cover;
```

## 9. Если ширина блока получается больше, чем вы задали

Проверьте наличие:

```css
* {
  box-sizing: border-box;
}
```

Без него `padding` и `border` могут увеличивать фактический размер элемента.

## 10. Если вы не понимаете, откуда появился отступ

Откройте DevTools.

Выберите элемент и посмотрите Box Model.

У браузера есть собственные стили для:

```text
body

h1

h2

p

ul
```

Поэтому часть отступов может существовать ещё до написания вашего CSS.

## 11. Не используйте большое количество `<br>`

Если вам нужно создать расстояние между элементами, не делайте:

```html
<br />
<br />
<br />
<br />
```

Используйте CSS:

```css
margin
```

или:

```css
padding
```

## 12. Не используйте пробелы для расположения элементов

Неправильно:

```html
Цена: 12 900 ₽
```

CSS должен отвечать за визуальное оформление и расстояния.

- [ ] Есть селекторы классов.

- [ ] Используется `line-height`.
- [ ] Используется `width` или `max-width`.
- [ ] Используется `padding`.
- [ ] Используется `margin`.
- [ ] Используется `border`.
- [ ] Используется `border-radius`.
- [ ] Стили не написаны через `style=""` непосредственно в HTML.

## Box Model

- [ ] Вы понимаете, где у карточки `content`.
- [ ] Вы можете показать её `padding`.
- [ ] Вы можете показать её `border`.
- [ ] Вы можете показать её `margin`.
- [ ] Вы можете объяснить разницу между `padding` и `margin`.

## Изображение

- [ ] Изображение загружается.
- [ ] Путь к изображению указан правильно.
- [ ] Изображение не выходит за границы страницы.
- [ ] Оно не выглядит случайно растянутым.
- [ ] Использован `border-radius`, если это соответствует дизайну.

## Код

- [ ] Названия классов понятные.
- [ ] Нет классов вида `block1`, `text2`, `red-box3`, если их можно назвать по смыслу.

- [ ] В CSS закрыты все фигурные скобки.
- [ ] После деклараций стоят точки с запятой.
- [ ] Нет повторяющихся правил, которые можно объединить.

## Проверка в браузере

- [ ] Страница открывается без ошибок.
- [ ] Все тексты читаются.
- [ ] Все элементы видны.
- [ ] Нет горизонтальной прокрутки из-за слишком широкого элемента.
- [ ] Страница проверена через DevTools.
- [ ] Вы можете определить, откуда приходит конкретный CSS-стиль.


Так интерфейс будет выглядеть аккуратнее.

## 3. Создайте визуальную иерархию текста

Главный заголовок должен визуально отличаться от обычного текста.

Например:

```text
H1 — самый крупный

H2 — немного меньше

обычный текст — основной размер

подписи — меньше и спокойнее
```

Не нужно делать весь текст одинакового размера.

## 4. Ограничивайте ширину длинного текста

Очень длинная строка текста плохо читается.

Вместо растягивания абзаца на всю ширину экрана можно использовать:

```css
max-width
```

## 5. Используйте спокойные границы

Для современных карточек чаще подходит что-то вроде:

```css
border: 1px solid #e5e5e5;
```

чем очень толстая чёрная рамка.

Но итоговый дизайн остаётся за вами.

## 6. Сравнивайте элементы между собой

Посмотрите на страницу как дизайнер.

Спросите себя:

- одинаковы ли радиусы у похожих карточек;
- одинаковы ли внутренние отступы;
- достаточно ли контрастная кнопка;
- хорошо ли читается вторичный текст;
- понятно ли, где начинается новая секция;
- не слишком ли много разных цветов;
- не слишком ли много разных размеров текста.

## 7. Проверяйте CSS через DevTools

Попробуйте прямо в браузере менять:

```css
padding

margin

font-size

color

border-radius
```

Это позволит быстрее понять, какое значение подходит.

После эксперимента перенесите итоговое значение в `style.css`.

## 8. Не бойтесь переделывать

Первая версия страницы редко выглядит хорошо.

Нормальный процесс разработки выглядит так:

```text
написали HTML
↓
добавили CSS
↓
открыли браузер
↓
увидели проблему
↓
исправили
↓
снова проверили
```

Это не ошибка в процессе.

Это и есть процесс frontend-разработки.

# Дополнительное задание повышенной сложности

Если основная работа выполнена раньше остальных, добавьте на страницу ещё три карточки:

```text
HTML

CSS

Основы адаптивной вёрстки
```

Каждая карточка должна иметь одинаковый класс:

```html
class="topic-card"
```

Внутри каждой карточки разместите:

- название;
- короткое описание;
- количество занятий;
- уровень сложности.

Все карточки должны получать базовое оформление из одного CSS-класса.

Не копируйте отдельный CSS для каждой карточки.

Цель дополнительной части — понять главный принцип повторного использования CSS-классов.

# Итог

В этой работе оценивается не сложность дизайна, а ваше понимание связи:

```text
HTML
+
CSS
```

HTML должен создавать правильную структуру.

CSS должен отвечать за внешний вид.

После выполнения задания вы должны уметь посмотреть на элемент интерфейса и определить:

```text
какой HTML-тег здесь подходит;

какой класс ему нужен;

какой у него фон;

какой размер;

какие внутренние отступы;

какие внешние отступы;

какая граница;

какой радиус;

как оформлен текст;

почему браузер применяет именно эти стили.
```
